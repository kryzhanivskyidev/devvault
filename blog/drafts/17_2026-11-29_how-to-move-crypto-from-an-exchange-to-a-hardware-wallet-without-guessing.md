# How to Move Crypto from an Exchange to a Hardware Wallet Without Guessing

The moment crypto leaves an exchange, support options shrink and self-custody begins. That is a feature—but only if the receiving wallet, network, address, and recovery process are correct. Guessing is incompatible with irreversible transfers.

This workflow applies to WhiteBIT and other centralized exchanges. It starts before the withdrawal screen, with an authentic device and a tested backup.

> **Quick verdict:** The safe transfer is a verified chain: authentic hardware, offline backup, device-confirmed address, matching network, small test, then main transfer.
>
> **Best for:** users moving long-term assets from an exchange to Ledger, Trezor, or another hardware wallet.
>
> **Look elsewhere if:** people who have not backed up the wallet or cannot identify the receiving network.

## Step 1: initialize the wallet

Buy from the manufacturer or an authorized seller. Initialize the device yourself and let it generate the recovery phrase. Write the phrase on an offline backup and store it separately from the device. Reject any preconfigured wallet or included seed phrase.

Install the official companion software from a verified domain. Update through the official application, not a link in an email or advertisement.

## Step 2: verify recovery

Use the manufacturer's supported recovery-check method or restore a test wallet before significant value arrives. A seed written incorrectly is not a backup. Never test it on a website, browser extension, or chat bot.

Keep the seed phrase secret from everyone, including exchange and wallet support. Legitimate support can help with software without learning the words.

## Step 3: add the correct account

Add an account for the exact asset and network. Some tokens share an address format across compatible networks, which can create false confidence. Confirm that the companion wallet displays and supports the token you intend to receive.

If a token depends on a smart-contract address, verify it through an authoritative source.

## Step 4: confirm the address on-device

Generate a receiving address and display it on the hardware wallet. Compare the full address or a strong set of characters with the computer. Trust the device screen when there is disagreement.

Copy the address from the verified interface. After pasting into WhiteBIT, compare it again. Clipboard malware specifically targets this step.

## Step 5: match the exchange network

Select the asset on WhiteBIT, then choose the network supported by the hardware-wallet account. Check withdrawal status, minimum, fee, and any memo/tag. Most personal hardware-wallet addresses do not use an exchange-style memo, but never assume—follow the destination format.

Do not choose a network solely because it is cheaper. Unsupported assets can become difficult or impossible to recover.

## Step 6: send and verify the test

Send a small amount above minimums. Save the transaction ID and watch it in the correct block explorer. Wait until the wallet displays the confirmed balance.

For tokens, verify the contract and amount. A balance shown by a portfolio tracker is useful, but the on-chain transaction and wallet account are the stronger evidence.

## Step 7: send the main amount

Repeat the address and network checks. If anything changed—the wallet app, address, network, firmware, or destination—treat it as a new route and retest. Send the main amount and save the transaction record.

Afterward, review how much remains on the exchange and whether that balance still has a defined near-term purpose.

## FAQ

### Why send a test if the address is correct?

A test validates the entire route: network, wallet support, address, minimum, fee, and your ability to observe the transaction.

### Can an exchange reverse a completed withdrawal?

Confirmed blockchain transfers are generally irreversible. Prevention is the reliable control.
